# Reference recordings

Twenty pseudonymized ring-sensor recording files will be distributed as assets of the [reference recordings release](../../releases/tag/reference-recordings-v1).

Each recording is an original de-identified, third-party research file. The files are approximately 1.33 GB in total and were not captured by this project.

The dataset's existing source, original repository URL, methodology, and licensing requirements remain documented in [the benchmark reproduction instructions](../../research/benchmarks/public_waveform/README.md).

Use is subject to **Creative Commons Attribution–NonCommercial 4.0** and the original release conditions. Attribution is required for any redistribution. The file naming is neutral and preserves the original participant pseudonyms (P1–P20).

Only publicly released third-party recordings belong in this release. Locally collected ring measurements, identity templates, BLE keys, and authentication secrets remain excluded from GitHub.
