# Data workspace

This directory is reserved for external wearable-signal recordings used in offline experiments.

The source recordings are not committed here. The collection is hosted separately, and any future redistribution must include the required license and source attribution.

For now, the repository contains the team's reproducible benchmark code and aggregate measurements in `research/benchmarks/public_waveform/`.

No personal biometric recordings, enrollment templates, or device credentials belong in this public repository.
